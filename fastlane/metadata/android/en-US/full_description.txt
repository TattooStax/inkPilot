inkPilot combines SMS, MMS, contacts, a studio reference gallery, a local calendar, and manual calling in one Android app for tattoo studios.

Messages use the phone's carrier, and MMS requires mobile data. Staff control recipients and sends. Studio records and imported reference images are stored on the device. The Studio archive exports its database, including agent settings and copies of some message text; it does not include the phone's SMS/MMS history or imported model weights. Archive import and restore are not yet available.

The optional LFM3 reply assistant is currently disabled while its exact local model and safety checks are qualified. It cannot answer cellular calls. An optional companion bridge can use a network connection when staff enable it; it is off by default. The app is open source at https://github.com/TattooStax/inkPilot.
