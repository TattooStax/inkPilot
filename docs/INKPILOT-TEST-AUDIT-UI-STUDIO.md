I read all 33 Kotlin test files in the assigned `ui`, `studio`, `phone`, `staged`, and `transport` directories end to end: 3,338 source lines, 36 classes, and 97 `@Test` methods. At pinned `e915096a`, the same directories held 21 files, 21 classes, and 82 methods (2,341 lines). The 12 new files account for the 15 additional classes and methods; the 21 existing files are unchanged between e915 and cacf2. This is a source audit; it does not claim emulator execution.

Paths below are relative to `app/src/androidTest/kotlin/org/fossify/messages/`. Each row identifies the production boundary, actual assertion, fixture and cleanup, and a practical limitation. `DB` means a randomly named private SQLite fixture closed and deleted; `default DB` means the app's actual Studio database, with only synthetic rows removed. No assigned test deliberately invokes a live phone call or carrier send.
