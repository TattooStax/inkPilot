## Verified source findings and isolated fixes

| Priority | Finding at pinned tree | Isolated fix and proof status |
| --- | --- | --- |
| P1 | Confirmed Forget queued deletion while old editor Save remained enabled (`ContactPanel.kt:79-84,95-105`), so immediate Save could restore private memory after deletion. | Retire editor before queueing deletion. `ContactForgetUiTest` queues the worker and attempts stale Save. |
| P1 | Locked SMS picker result could take a URI grant and write `ComposerStore` (`StudioHomeActivity.kt:320-332`). | Early discard while locked. `LockedComposerPickerTest` covers locked discard and unlocked normal attachment. |
| P1 | Contact Save auto-dismissed before async repository result (`ContactPanel.kt:98-105`); failed write lost typed staff fields. | Keep editor open until success; disable fields during pending write; reenable and show error on failure. `ContactSaveFailureUiTest` injects SQLite failure, checks retained text, then retries. |
| P1 | Unmanaged Contact edit dialog did not enter Activity saved state (`ContactPanel.kt:49-106`, Home onSave `313-318`); rotation could lose unsaved memory/source/pause. | `ContactEditState` saves only the active draft and reopens it when Contacts canvas is attached. `ContactEditRotationUiTest` covers recreation, uncommitted data and Cancel. |
| P2 | Delayed vCard import selected Contacts after staff moved to another tab (`VCardPreviewPanel.kt:50-61`). | Completion navigates only if the original Attachment route is current. `VCardImportRouteUiTest` holds worker, switches to Calendar and checks both import and selected tab. |
| P2 | Delayed contact row read opened its editor over a newer tab (`ContactPanel.kt:40`). | Open only if originating Contacts ScrollView remains attached. `ContactOpenRouteUiTest` holds the read, selects Phone and asserts no dialog. |

All six fixes are on isolated `test/ui-contact-save-route` commit `60c00b4e51c5f12845825cfff1c14bedbdc06b44`, with later **local-only** one-line test compile correction `756c7e7b` (`AccessibilityNodeInfo.AccessibilityAction.ACTION_SHOW_ON_SCREEN.id`) and local-only Detekt refactor `a2e48101`. The integration tree independently applied the action correction as `047afc5e`. Local file-size ratchet, shell syntax and diff checks pass. Hosted ratchet run `41999176653` passed. Device run `41999176773` stopped at the pre-correction AndroidTest compile error and ran no emulator tests; no device success can be claimed for these fixes yet. Standalone build run `41999176667` assembled and ran reusable-module tests, then failed Detekt on `StudioCanvasRendering` LongParameterList, `StudioHomeActivity` TooManyFunctions/MagicNumber and unrelated base `ComposerSharedMedia` NestedBlockDepth. Local `a2e48101` targets the first three without suppression; it has not run in CI.

The suspected accepted-send tab hijack is **disproved** for Compose: `StudioHomeActivity.kt:142-144` passes `ComposerRouteCoordinator.completeCompose`, whose `current == source` guard (`ComposerRouteCoordinator.kt:45-50`) prevents a late callback from changing a newer route. Existing-thread composer has a positive thread ID and does not enter the new-thread route path.
